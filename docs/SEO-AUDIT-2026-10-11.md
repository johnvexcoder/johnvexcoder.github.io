**Remaining issues and limits**

- These improvements are local and ready to publish. No commit, push, production deployment or Search Console submission was performed. The existing V2 directory is not an independent Git repository; it inherits an unrelated parent repository, so that parent was not staged or committed. The current source was identified through release records and exact semantic comparison with live HTML.
- Some long project captures remain comparatively large: Monthsary ~998 KB, MovieFlix ~659 KB, ARKOSENYO ~465 KB. They remain lazily loaded in the archive. Further screenshot resizing/compression needs a dedicated readability check across animated, full-length captures; this audit preserves those visuals and interactions.
- MovieFlix’s live demo uses the already-documented private/self-hosted Tailscale destination and may require network access. Its public case-study content remains available through normal static anchors.
- Google indexing, search-result rendering, rankings and eligibility for rich-result presentation were not established by these checks. Structured data was parsed and locally validated, with no new business/review claims; external Rich Results/Search Console validation and field Core Web Vitals are remaining verification steps after deployment.
