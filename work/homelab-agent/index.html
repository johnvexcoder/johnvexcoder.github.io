01 / Context

The problem it addresses

Complements the Proxmox API with host-local telemetry while keeping collection modular, outbound-only, and resilient when optional tools or individual plugins are unavailable.

02 / Build

What the project does

A modular, plugin-based telemetry agent built specifically for HomeLab OS. It runs on Linux hosts and reports the node-local information that the Proxmox API does not expose, including temperatures, fan speeds, SMART disk health, Docker containers, kernel details, services, and network health. Six isolated plugins auto-detect the host environment, collect at independent intervals, and securely report through the Agent Core without opening inbound ports.

03 / Architecture decision

Architecture decision

Host-local collection is separated into isolated plugins. Each runs independently, so missing optional tools or one failing collector does not take down the agent.
