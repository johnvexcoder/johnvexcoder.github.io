01 / Context

The problem it addresses

Explores how a visually distinctive bakery can still support a deep, understandable shopping journey. Catalog discovery, product options, box building, saved items, and checkout are connected into one responsive interface.

02 / Build

What the project does

A polished commerce concept built with Next.js, React, and TypeScript. Customers can browse a detailed donut catalog, search and filter products, save favorites, customize products, assemble a box, manage a persistent cart, and follow a complete demonstration checkout flow. Framer Motion supports the interface transitions, Zustand manages browser state, and Zod validates structured inputs.

03 / Experience decision

Experience decision

Commerce depth is organized around a clear path from discovery to customization, saved items, box building, cart review, and a clearly labelled demonstration checkout.
