01 / Context

The problem it addresses

Solves the pain of managing large photo libraries. Batch compression with parallel processing, duplicate detection to free up storage, and detailed reporting whether running from a GUI or a script.

02 / Build

What the project does

A powerful, cross-platform image compression tool — modern PySide6 GUI plus full CLI. Batch-compress thousands of images, detect duplicates with perceptual hashing, preserve metadata, and generate detailed reports. Supports JPEG, PNG, WebP, AVIF, GIF, and RAW formats with optional external tool acceleration.

03 / Product decision

Product decision

One compression engine supports two workflows: a visual desktop interface for everyday use and a CLI for repeatable batch automation.
