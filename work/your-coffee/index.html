01 / Context

The problem it addresses

Turns a broad drink menu into a clear, personal ordering flow. Search, categories, customization choices, a locally saved cart, and a responsive checkout make the fictional café easy to explore on any device.

02 / Build

What the project does

A framework-free café experience built with semantic HTML, modern CSS, and vanilla JavaScript. The site includes a 33-drink catalog, category filters, search, detailed drink customization, a persistent browser cart, promotional pricing, and demonstration checkout and payment views. Hash-based routing keeps the multi-view experience compatible with static Vercel hosting.

03 / Interface decision

Interface decision

A small hash-based router supports a complete multi-view ordering journey while keeping the project framework-free, statically hosted, and easy to navigate with browser history.
