01 / Context

The problem it addresses

Provides a clean, fast, distribution-aware ZSH experience without the bloat of frameworks like Oh My Zsh. The prompt adopts the color of your distribution while keeping one consistent, native layout.

02 / Build

What the project does

A lightweight, framework-free ZSH configuration that delivers a native, professional terminal experience. Auto-detects the running distribution and applies per-distribution color themes. No framework, no plugin manager, no Nerd Font requirement. Four prompt layouts, smart command-not-found with typo suggestions, and a fully reversible installer.

03 / System decision

System decision

Distribution-aware styling and a reversible installer provide a consistent shell experience without a framework or plugin manager.
