01 / Context

The problem it addresses

Administrative Windows operations often sprawl across ad-hoc scripts. WinOps centralizes them behind a vetted, declarative, and safely executable engine with rollback and journals.

02 / Build

What the project does

JohnVex WinOps is an enterprise Windows administration suite built on a modular Windows PowerShell 5.1 engine. It ships Community, Professional, and Enterprise edition boundaries, enterprise-safe licensing diagnostics, system inventory, health auditing, network diagnostics, DISM and SFC handlers, a declarative operation catalog with a fixed code allowlist, dry-run planning with explicit risk acceptance, verified registry writes, operation journals, rollback, and structured JSONL session logging. Preserves the audited Win11Max.bat as the Community compatibility engine.

03 / Safety decision

Safety decision

Administrative operations are organized behind a declared catalog with risk acceptance, journals, dry runs, and rollback support instead of scattered scripts.
