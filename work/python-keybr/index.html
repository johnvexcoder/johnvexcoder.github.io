01 / Context

The problem it addresses

Bringing an adaptive, keybr.com-style typing experience to the terminal. Tracks per-letter accuracy, unlocks letters progressively as you improve, and provides a full keyboard diagnostic tool.

02 / Build

What the project does

A terminal-based typing trainer inspired by keybr.com, built in pure Python with the curses library. Features 6 practice modes, real-time WPM and accuracy tracking, persistent progress, adaptive letter unlocking, bigram tracking, and a professional keyboard diagnostic with NKRO monitoring.

03 / Interaction decision

Interaction decision

Real-time feedback, persistent progress, and adaptive letter unlocking bring deliberate typing practice into a keyboard-first terminal workflow.
