01 / Context

The problem it addresses

Turns local and NAS media folders into a polished, private streaming platform. Accurate byte-range seeking, protection against bulk downloads, and full admin control all under your own infrastructure.

02 / Build

What the project does

A self-hosted, private media streaming platform. Scans local media folders, identifies movies and shows, fetches metadata from TMDB, analyzes codecs with FFprobe, and streams video over HTTP 206 partial-content requests. Includes multi-profile accounts, trial accounts, adaptive quality transcoding, subtitles, and a full administrative command center.

03 / Systems decision

Systems decision

Scanning, metadata, byte-range delivery, and transcoding are treated as separate responsibilities so local media remains browsable and seekable across devices.
